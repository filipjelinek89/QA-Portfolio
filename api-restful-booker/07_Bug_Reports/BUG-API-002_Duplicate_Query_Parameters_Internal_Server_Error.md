## 2. Defect Summary

During execution of **TC-GETIDS-027**, the request:

``` http
GET /booking?firstname=Susan&firstname=John
```

returned **HTTP 500 Internal Server Error**.

The API failed to process a request containing duplicate query
parameters. A robust API should either ignore duplicate parameters,
process one of the supplied values consistently, or return **HTTP 400
Bad Request**. Returning **HTTP 500 Internal Server Error** indicates an
unhandled server-side exception.
