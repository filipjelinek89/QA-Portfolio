# 1. Purpose

This document provides a high-level overview of all API Test Execution activities performed during the Restful Booker API Testing Project.

It serves as the central index for sprint-specific execution reports and provides a consolidated view of project execution progress.

Detailed execution reports are maintained separately for each sprint.

---

# 2. Scope

This master document does not contain detailed execution results.

Instead, it provides:

- Sprint execution overview
- Execution progress
- Repository navigation
- Execution statistics
- Traceability overview

Detailed execution results, evidence and defect information are maintained in individual sprint execution reports.
