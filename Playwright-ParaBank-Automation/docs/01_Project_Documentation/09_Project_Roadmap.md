# Purpose

This roadmap defines the long-term development plan for the Playwright automation framework.

The project is designed to evolve gradually from a simple automation framework into a professional QA automation portfolio that demonstrates real-world engineering practices.

---

# Project Vision

The primary goal is not only to automate the ParaBank application, but also to build a scalable, maintainable, and production-like automation framework.

The project follows the same business scenarios as the Manual QA project while implementing them with Playwright and TypeScript.

---

# Development Strategy

The roadmap follows an incremental approach.

Each completed phase becomes the foundation for the next one.

```text
Framework

↓

Automation

↓

```
