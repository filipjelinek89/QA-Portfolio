# Playwright-ParaBank-Automation

> **Professional End-to-End UI Automation Framework using Playwright + TypeScript**

## Project Overview

**Project:** Playwright-ParaBank-Automation  
**Author:** Filip Jelinek  
**Version:** 1.0  
**Status:** 🚧 In Progress

This repository demonstrates a professional Playwright automation framework built around the ParaBank demo banking application.

The project is intentionally developed as a standalone repository while mapping automated tests to the existing ParaBank Manual Testing Project.

---

## Objectives

- Build a maintainable Playwright automation framework
- Apply Page Object Model (POM)
- Automate critical business workflows
- Include happy path, negative, validation and boundary testing
- Generate HTML reports, screenshots, traces and videos
- Execute tests locally and through GitHub Actions
- Maintain traceability between manual and automated test cases
